## Project Overview

AttendEase is a smart attendance management web application built using React. It helps students monitor their subject-wise attendance, manage their timetables, and make informed decisions about attending classes.

## Key Features

- **Attendance Dashboard:** View attendance information and subject-wise summaries.
- **Subject Health:** Monitor attendance percentages for individual subjects.
- **Daily Attendance Tracking:** Mark classes as present or absent.
- **Smart Attendance Planning:** Understand how missing a class may affect your attendance percentage and the required attendance threshold.
- **Timetable Management:** View and manage scheduled classes.
- **Analytics:** Review attendance statistics for individual subjects.
- **Data Persistence:** Store attendance information using browser LocalStorage.

## Technologies Used

- React.js
- JavaScript (ES6+)
- HTML5
- CSS3
- React Router
- Browser LocalStorage

## Installation and Setup

1. Clone the repository:

   ```bash
   git clone https://github.com/manshagarg2006/AttendEase.git
   ```

2. Navigate to the project directory:

   ```bash
   cd AttendEase
   ```

3. Install the dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in the terminal to access the application.

## Project Objective

The objective of AttendEase is to make attendance tracking more organized and practical by combining attendance records, timetable management, and subject-wise analytics in a single application.
